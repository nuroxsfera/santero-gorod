# Santero Город

Городской суперсервис. Всё для жизни в городах России.

Транспорт • События • Работа • Места • Недвижимость • Карта • Помощник

## Стек

- Next.js 16 (App Router)
- Tailwind CSS 4
- Framer Motion
- TypeScript

## Запуск

```bash
npm install
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000)
