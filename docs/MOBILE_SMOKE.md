## Обязательные шаги

- [ ] Splash → экран города (Новосибирск по умолчанию)
- [ ] «Начать · Новосибирск» → главная, бейдж «Пилот»
- [ ] Выбор другого города → travel → главная с новым именем
- [ ] Карта: тайлы OSM, ≥1 синий маркер, тап → sheet
- [ ] Места: список + кнопка «Карта»
- [ ] Новости: demo-баннер, фильтры, открытие статьи
- [ ] Работа: список вакансий demo
- [ ] Поиск: запрос «зоопарк» → hit place
- [ ] Вкладка «Ещё»: список «скоро»
- [ ] Bottom nav: иконки видны, active highlight
- [ ] Нет горизонтального overflow на 375px
- [ ] Safe area снизу не режет nav (iOS)

- [ ] Demo без пометки как «живые» данные
- [ ] Белый экран / crash на карте
