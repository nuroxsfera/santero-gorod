## 1. Ядро приложения (~75%)

### Сделано
- Splash-анимация SG (Framer Motion)
- Выбор города / CitySearchScreen
- Travel-переход при смене города
- Главный экран: collapsible header, карточки, floating bottom nav
- Связка экранов: news, jobs, city-list
- Палитра Santero `#058BED`, mobile-first `h-dvh`

### Нужно сделать
- Иконки вкладок вместо плейсхолдеров
- Карточки «Транспорт / События / Места» как реальные разделы
- Полировка анимаций и safe-area на всех устройствах
- Онбординг, настройки, профиль пользователя

### Успехи
- Единый screen state machine в `page.tsx`
- Стиль близок к референсам банковских apps

### Проблемы
- Вся навигация в одном `page.tsx` (раздувается)
- Нет отдельного layout/router по разделам
- Десктоп-адаптация слабая

## Рекомендуемый порядок дальше

1. Локально: `npm i && npm test && npm run build` — закрыть дыру CI.
2. Вынести экраны из `page.tsx` (роутинг / layouts).
3. Backend + auth как фундамент для Новостей и Работы.
4. Первый легальный источник новостей **или** работодательский поток вакансий.
5. Модули Транспорт / События / Места — после стабилизации ядра.

## Как читать проценты

- **80% Geography** = готовый клиентский контракт, не «готово к миллионам городов».
- **70% / 65% News/Jobs** = полный демо-путь в UI + архитектура, без production-данных.
- **~55% продукт** = можно показывать кликабельный прототип; до запуска не хватает backend, auth и реальных данных.
