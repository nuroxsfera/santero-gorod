# Backend Santero Город — этап 3 (фундамент)

## Что есть сейчас

HTTP API на Next.js Route Handlers (без отдельного сервера и без платной БД):

| Метод | Путь | Данные |
|-------|------|--------|
| GET | `/api/v1/health` | статус сервиса |
| GET | `/api/v1/news/feed` | лента (пока **demo**) |
| GET | `/api/v1/news/:id` | статья (пока **demo**) |
| GET | `/api/v1/jobs/vacancies` | вакансии (пока **demo**) |
| GET | `/api/v1/jobs/vacancies/:id` | вакансия (пока **demo**) |

Ответы помечают `isDemo` / `warning`, если контент демонстрационный.

Клиент UI **по умолчанию** по-прежнему ходит в `InMemory*Repository` (без обязательного API).
Подготовлен `HttpNewsRepository` для постепенного переключения.

## Чего ещё нет
