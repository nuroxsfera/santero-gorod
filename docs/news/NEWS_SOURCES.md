# NEWS_SOURCES — политика и подключение источников

## Статус

| Источник | Проверен | Подключён | Примечание |
|----------|----------|-----------|------------|
| Santero Demo (`demo-santero`) | да (внутренний) | да | Только `isDemo: true`, не выдаётся за реальные новости |
| Официальные API СМИ / госорганов | нет | нет | Планируется |
| Разрешённые RSS | нет | нет | Планируется после юридического OK |
| Партнёрские интеграции | нет | нет | По договору |

**Автоматический сбор новостей сейчас не работает.**

## Требования к законному использованию

1. Использовать только материалы, на которые есть право: лицензия, API ToS, партнёрский договор, RSS с явной политикой перепечатки.
2. Не копировать полный текст и изображения без прав.
3. Всегда сохранять атрибуцию: название источника, URL оригинала, дата, при наличии — автор.
4. Помечать синтетические/демо-данные флагом `isDemo: true` и показывать это в UI.
5. При сомнении в правах — не подключать источник.

## Допустимые типы источников

- Официальные HTTP API с документированными условиями.
- RSS/Atom, если политика источника допускает агрегацию заголовков/анонсов.
- Партнёрские фиды по договору.
- Собственные публикации Santero (редакция / UGC с модерацией) — в будущем.

Недопустимо: скрейпинг платных/закрытых сайтов, массовое копирование full-text без лицензии, выдача чужих материалов без ссылки.

## Обязательные поля при импорте

- `title`, `summary` (или краткий excerpt)
- `sourceId`, `sourceName`, `originalUrl`
- `publishedAt` (ISO)
- `contentHash` (для дедупликации)
- `geo`: `scope` + `localityId` / `regionId` из **Geography v1.0**
- `isDemo`
- опционально: `categoryId`, `imageUrl`, `body` (только при праве)

## Атрибуция, дедуп, география

- Атрибуция в карточке и на странице — имя источника + ссылка на оригинал.
- Дедуп по `contentHash`.
- География только стабильные ID Geography; при неоднозначности не угадывать город по заголовку.

## Как добавить новый источник

1. Юридическая проверка → запись в таблицу статуса.
2. Адаптер ingestion → `NewsArticle[]`.
3. Регистрация `NewsSource` (`isDemo: false` только для реальных).
4. Тесты фильтрации и дедупа.
5. Feature-flag для production.
