# Оценка RSS: Новосибирская область / Тогучин

Дата проверки: 2026-10-15.

## Кандидаты

| Источник | URL | Результат |
|----------|-----|-----------|
| Правительство НСО (nso.ru) | /rss, /news/rss | **403** с нашей среды — публичный RSS не подтверждён |
| Администрация Тогучинского р-на (toguchin.nso.ru) | /rss | **403** |
| **Тогучинская газета** (toggazeta.ru) | https://toggazeta.ru/rss (= /feed/) | **200**, RSS 2.0, WordPress |

### toggazeta.ru — факты

- Описание канала: «Интернет издание Тогучинского района».
- Обновление: hourly (заявлено в RSS).
- В ленте есть заголовок, link, pubDate, категории, description (HTML).
- Примеры заголовков (15.10.2026): «В Тогучине выпал первый снег», региональные вести НСО.

### Права и атрибуция

На сайте **не найдена** явная публичная «оферта на автоматическое использование RSS / полный текст» в рамках этой проверки.
Издание местное (ГАУ НСО «Редакция газеты «Тогучинская газета»» по открытым реестрам — не партнёр Santero).

**Вывод:** автоматический ingest **не включаем** в прод-ленту без вашего явного OK.
Безопасно готовить только **метаданные**: title, originalUrl, publishedAt, sourceName + ссылка на оригинал. **Без** полного body и **без** картинок.

### Альтернативы (если откажетесь от toggazeta)

1. Письменный запрос редакции toggazeta.ru на использование заголовков+ссылок.
2. Официальный канал nso.ru — уточнить у пресс-службы наличие RSS/API.
3. Федеральные агентства с **явными** правилами (часто запрещают RSS-агрегацию без договора — отдельно проверять).

## Статус в коде

- Есть парсер метаданных + unit-тесты на фикстуре.
- Preview API **выключен**, пока env `ENABLE_RSS_PREVIEW=1` не задан **вами**.
- Клиент и основная лента **не** переключены на RSS.
